## 第4章: AIガバナンス

### アジャイル・ガバナンス

AIガバナンスは、一度ルールを作って終わるものではない。外部環境やAIの利用状況、リスクの変化に応じて、次のサイクルを継続的に回すことが重要。

1. 環境・リスク分析を実施する
2. AIガバナンスのゴールを設定する
3. AIマネジメントシステムを設計する
4. 有効性を継続的にモニタリング・評価し、改善する
5. 変化に応じて、再び環境・リスク分析へ戻る

### AI事業活動を担う3つの主体

| 主体 | 主な役割 |
| --- | --- |
| AI開発者（AI Developer） | データ前処理・学習を行い、AIモデルを開発する |
| AI提供者（AI Provider） | AIモデルを組み込み、AIシステム・サービスとして提供する |
| AI利用者（AI Business User） | 提供されたAIシステムを業務・サービスで利用する |

各主体が、役割や影響範囲に応じて安全性、公平性、透明性、説明責任などに取り組む。

### AI新法

- 正式名称: **人工知能関連技術の研究開発及び活用の推進に関する法律**（通称: AI法、AI新法）
- 2025-06-04に公布・一部施行、2025-09-01に全面施行。
- AIの研究開発・活用を推進しつつ、リスクに対応することを目的とする、日本初のAI分野に特化した基本法。
- 4章28条で構成され、内閣にAI戦略本部を設置。内閣総理大臣が本部長、全ての国務大臣が構成員となる。
- 事業者には国等の施策への協力が求められ、国は情報収集・調査・分析を行い、必要に応じて指導・助言・情報提供等を行う。

### AI事業者ガイドラインとの関係

| 観点 | AI事業者ガイドライン | AI新法 |
| --- | --- | --- |
| 性格 | 事業者による自主的な取組を促すソフトロー | AI研究開発・活用の推進と適正性確保のための法律 |
| 国の調査 | 直接の調査権限を定めない | 情報収集、調査・分析、必要な対策検討を規定 |
| 事業者への対応 | 実務上の指針を提示 | 国等の施策への協力、指導・助言・情報提供等の仕組み |

## 第5章: LM・LLMとプロンプト基礎

### LMとLLM

| 用語 | 内容 |
| --- | --- |
| LM（Language Model） | 単語やトークンの並びを確率的に扱い、次に続く語などを予測する言語モデル |
| n-gramモデル | 直前のn-1語など、限られた語の並びと出現頻度を使って次の語を予測する手法 |
| ニューラル言語モデル | 大量のテキストコーパスをニューラルネットワークで学習し、より複雑な文脈を扱う言語モデル |
| LLM（Large Language Model） | 大量データと多くのパラメータを用いて学習した大規模言語モデル。幅広い言語タスクに対応する |

### LLMの学習

- **事前学習（pre-training）**: 大量のテキストから言語の規則・文脈・知識を学ぶ段階。一般に自己教師あり学習で行われる。
- **ファインチューニング（fine-tuning）**: 特定のタスク、領域、指示への対応力を高めるために追加学習する段階。
- ファインチューニングでは、モデルの再学習、ハイパーパラメータ調整、評価を行う。

### TemperatureとTop-p

| パラメータ | 役割 | 値を上げた場合の傾向 |
| --- | --- | --- |
| Temperature | 次の語の選択におけるランダムさを調整する | 多様・創造的になる一方、出力がぶれやすくなる |
| Top-p | 確率の高い候補を、累積確率pまでに絞る（nucleus sampling） | 候補の幅が広がり、多様な出力になりやすい |

事実確認や定型的な業務では低めのランダムさ、アイデア出しでは多様性を許容するなど、用途に応じて使い分ける。

## 不明用語の整理

| 用語 | 一言での理解 |
| --- | --- |
| アカウンタビリティ | AIの結果や対応について、関係者が説明し責任を果たすこと。アカウント保護とは別の概念。 |
| ソフトロー | 法的な強制力・罰則を直接伴わないが、望ましい行動を示し実務に影響を与える指針・ガイドライン等。 |
| n-gramモデル | 直前の語の並びと頻度で、次の語を予測する比較的単純な言語モデル。 |
| ニューラル言語モデル | ニューラルネットワークで語や文脈の関係を学ぶ言語モデル。 |
| Temperature / Top-p | 生成時の語の選び方を調整し、出力の安定性・多様性に影響するパラメータ。 |
