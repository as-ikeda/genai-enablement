## 優先度A: 第3章の生成AIモデル・学習手法

| 用語 | 最低限の理解目標 |
| --- | --- |
| RBM | 完全結合ボルツマンマシンを入力層・隠れ層に制約して学習を効率化したモデルと説明できる。 |
| MLM / NSP | MLMは隠した単語を前後の文脈から予測、NSPは2文の前後関係を予測するBERTの学習タスクと区別できる。 |
| RLHF / 憲法AI | RLHFは人の評価を利用した強化学習、憲法AIは原則に基づく自己評価を利用する安全性向上手法と区別できる。 |
| 自己回帰 / ディフュージョン | 自己回帰は次の要素を順に予測、ディフュージョンはノイズ除去を繰り返して生成すると区別できる。 |
| RNN / Transformer | RNNは順番に処理、Transformerは自己注意と並列処理を用いると説明できる。 |

## 優先度B: 第1〜2章の用語

| 用語 | 最低限の理解目標 |
| --- | --- |
| ラベリング | 教師あり学習用に、データへ正解ラベルを付ける作業と説明できる。 |
| シナプス | ニューロン間の接続部であり、AIでは接続の重みと関連づけて説明できる。 |
| 訓練データ / 検証データ | 訓練は学習に使用、検証は学習途中の性能確認に使用と区別できる。 |
| 次元削減 | 特徴量の数を減らし、可視化・計算効率を改善する手法と説明できる。 |
| バイアス | データや設計に由来する偏りで、不公平・誤った結果につながる可能性があると説明できる。 |
| チューリングテスト / 中国語の部屋 | 前者は機械の知能を会話で判定する考え方、後者は記号操作だけでは理解といえないという思考実験と区別できる。 |

| 用語 | 最低限の理解目標 |
| --- | --- |
| o1 / o3ファミリー | o1は推論能力を高めたシリーズ、o3-proは厳しい要件向けの高精度モデルと区別できる。 |
| Spaces / Copilot Studio / Operator | Spacesは開発協業、Copilot Studioは独自Copilot構築、Operatorはブラウザ操作を伴うタスク実行と用途を区別できる。 |
