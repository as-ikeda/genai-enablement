## 全体像

今回の学習範囲は、生成AIの代表的なモデル・サービスの整理が中心。

- ChatGPTは、GPT系モデルを利用した対話型AIとして普及した。
- GPT-4以降は、性能向上、ハルシネーション低減、マルチモーダル対応が重要な観点になる。
- GPT-4o、oシリーズ、GPT-4.1、GPT-5などは、用途や設計思想が異なるため、単純な世代順だけで覚えない。
- Sora、Operator、Codex、image generationは、生成AIが文章生成だけでなく動画生成、ブラウザ操作、開発支援、画像生成へ広がっている例として押さえる。
- Gemini、Claude、Copilotは、提供会社・強み・利用シーンで比較して覚える。

## ChatGPT / GPT系モデル

### ChatGPT

- 特定用途に合わせてモデルを微調整するファインチューニングの考え方と関連する。
- 数か月で1億ユーザー規模に到達した生成AIの代表例。
- 初期のChatGPT/GPT-3.5系では、学習データの期限による情報制約があった。

試験ポイント:

- ChatGPTは「生成AI」「大規模言語モデル」「対話型AI」の代表例として整理する。
- 常に最新情報を知っているわけではない点、ハルシネーションが起こり得る点を押さえる。

### GPT-4

- 2023年3月リリース。
- GPT-3.5と比べて性能が向上。
- ハルシネーションの低減が特徴の1つ。
- テキストだけでなく画像なども扱えるマルチモーダル性が重要。
- 多言語処理の精度向上もポイント。

メモ:

- ハルシネーション: AIが意味のない、または不正確な情報をもっともらしく生成する現象。
- マルチモーダル: テキスト、画像、音声、動画など複数種類のデータを扱えること。

### Code Interpreter

- 2023年7月リリース。
- Pythonコードを作成し、実行できる機能。
- データ分析、グラフ作成、数学的計算、ファイル読み込み処理などを依頼できる。

試験ポイント:

- 「AIがコードを実行して分析できる機能」として理解する。
- 現在の名称や提供形態は変わり得るため、試験では機能の意味を優先して覚える。

### GPTs

- ChatGPTを特定用途向けにカスタマイズできる機能。
- 振る舞いの設定、外部API連携、特定タスクへの特化が可能。
- 作成したGPTsをGPT Storeで公開し、他ユーザーが利用できる。

### GPT-4o

- 2024年5月リリース。
- `omni` は「すべての」を意味する。
- テキスト、画像、音声などを統合的に扱うオムニモーダルモデルとして整理する。
- 音声応答の速度向上が特徴。

### oシリーズ / 推論モデル

メモ上では `GPT-o1`、`GPT-o3`、`GPT-o4` と記載しているが、公式表記では `OpenAI o1`、`OpenAI o3`、`o4-mini` などの表記が使われる。試験対策では「GPT-4o」と「oシリーズ」は別系統として混同しない。

#### OpenAI o1

- 2024年に発表された推論モデルシリーズ。
- 回答前により深く考える設計思想を持つ。
- 研究、数学、ソフトウェア開発など、難易度の高いタスクに強い。

#### OpenAI o3 / o3-pro

- 推論特化型の大規模言語モデル。
- 科学、数学、コードなど複雑領域の正答率向上が特徴。
- `private chain-of-thought` のような内部推論に関する表現は、ユーザーが直接見る回答文とは区別して理解する。

#### o4-mini

- oシリーズの一部として整理する。
- `GPT-4o` と `o4-mini` は名前が似ているが、前者はオムニモデル、後者は推論モデル系列として区別する。

### GPT-4.1

- GPT-4系列を開発者向け業務に最適化した改良版として整理。
- 長いコンテキスト処理、コード修正、指示追従、低レイテンシー、低コストなどがキーワード。
- mini、nanoなどのサイズ違いがあり、用途と計算資源に合わせて使い分ける。

### GPT-5

- メモ上では `GPT-5`、`GPT-5 thinking`、`GPT-5 pro` として整理。
- 高い専門性や推論を必要とするタスクに対応するモデル群として理解する。
- リリース時期、モデル名、性能比較は変化しやすいため、公式情報での確認対象にする。

## OpenAIの主な生成AI関連機能

### Sora

- テキストや画像から動画を生成するAI。
- Transformer系のアーキテクチャを活用した拡散モデルとして整理。
- 静的ノイズから段階的にノイズを除去し、動画へ変換する考え方。
- ストーリーボード機能により、フレームごとの入力や意図を指定し、時間軸に沿った構成を作れる。

### Operator

- ブラウザ操作に特化したAIエージェント。
- ユーザーがタスクを入力すると、ブラウザを使ってクリックや入力などを実行する。
- 商品購入、予約、住所や支払い情報の転記などのユースケースがある。
- 2025年7月以降は、ChatGPT agentへの統合という流れも押さえる。

### Codex

- ソフトウェア開発向けAIエージェント。
- 機能追加、バグ修正、PR作成など、複数の開発タスクを並行処理できる。
- ターミナルログやテスト結果を証拠として提示し、既存のGit/PRフローに組み込める。

社内展開メモ:

- 今回の資格学習PJ自体が、Codexを使って学習計画、学習ログ、Git運用をプロジェクト化する実例になっている。

### Image generation

- 画像生成機能。
- 従来の拡散モデルだけでなく、自己回帰モデルの考え方も出てくる。
- 画像をトークンとして扱い、順に生成することで、細かな画像生成や画像内文字の生成能力向上につながる。

## その他の主要生成AI

### Gemini

- Google DeepMindが提供する生成AIファミリー。
- テキスト、画像、音声、動画、PDFなどを扱うマルチモーダル性が特徴。
- 長文コンテキスト、推論、エージェント的なツール呼び出しがポイント。
- Gemini Nanoのように、スマホやデバイス上での利用を意識したモデルもある。

覚え方:

- `Gemini = Google / マルチモーダル / 長文処理 / デバイス展開`

### Claude

- Anthropicが提供する生成AIファミリー。
- 安全性を重視する設計思想。
- Constitutional AIという訓練手法が特徴。
- Haiku、Sonnet、Opusなど、用途別のモデル階層がある。
- 長いコンテキストと文書処理、コードや文書を並行生成するArtifacts機能がポイント。

覚え方:

- `Claude = Anthropic / 安全性 / Constitutional AI / 長文・文書処理`

### Copilot

- Microsoft系の生成AIアシスタント。
- Office製品との統合が強み。
- Copilot Studioにより、自社向けの業務アプリやAI支援を構築できる。
- GitHub Copilot、Security Copilotなど、開発・セキュリティ領域にも展開している。
- Copilot+ PCではNPUを活用したローカルAI処理も関係する。

覚え方:

- `Copilot = Microsoft / Office連携 / 業務支援 / 開発支援`

## LINE学習結果

| 判定 | 問題テーマ | 自分の理解 | 次に覚えるポイント |
| --- | --- | --- | --- |
| ○ | GANは生成モデルか | 正解 | GANは生成モデル。生成器と識別器の関係で覚える |
| × | ディープラーニングの計算処理高速化に使われる半導体チップ | GPU | DL高速化はGPU。NPUとの違いも整理する |
| ▲ | 時系列データの処理に適したニューラルネットワーク | RNN | 音声・自然言語・時系列データはRNN/LSTM、現在はTransformerとの違いも重要 |
| ○ | 現在のAI（ANI）が苦手なこと | 学習していない新しい状況への対応、常識的判断 | ANIは特定タスクに強いが、汎用的な常識判断は苦手 |

## 不明・曖昧な用語

次回以降で用語集化する。

| 用語 | 今の仮理解 | 次に確認する観点 |
| --- | --- | --- |
| 自己回帰モデル | 過去の出力や前の要素を使って次を予測・生成するモデル | 文章生成・画像生成での使われ方 |
| コンテキスト | モデルが参照できる文脈・入力範囲 | コンテキスト長、トークンとの関係 |
| トークン | モデルが処理するテキストや画像などの最小単位 | 文字、単語、画像トークンの違い |
| SOTA | State of the Art。現時点で最高水準の性能 | 試験では「最先端性能」程度で覚える |
| レイテンシー | 応答までの遅延時間 | 低レイテンシー=反応が速い |
| シームレス | 境目なく自然につながること | 業務フローに組み込まれる文脈で使う |
| 双方向の低遅延ボイスインタラクション | 音声で自然に会話できる低遅延のやり取り | 音声AI・リアルタイム対話の特徴 |
| マルチモーダル推論 | 複数種類のデータを合わせて推論すること | テキスト、画像、音声、動画を横断して判断する例 |
| 拡張リッド設計 | メモ上の表記が曖昧 | Claude関連の正式表現を再確認する |
| NPU | AI処理に特化した半導体チップ | GPUとの違い、端末内AIとの関係 |

## 試験で問われそうなこと

- ChatGPT、GPT-4、GPT-4oなどの代表的な特徴。
- ハルシネーション、マルチモーダル、オムニモーダルの違い。
- Sora、Operator、Codex、GPTs、Code Interpreterが何をする機能か。
- Gemini、Claude、Copilotの提供会社と特徴。
- GPU、RNN、GAN、ANIのような基礎用語の短答。
- 最新モデル名よりも、機能・用途・リスク・限界を問われる可能性が高い。

## 実務・社内展開に使えそうなこと

- 生成AIは文章生成だけでなく、画像、動画、音声、ブラウザ操作、開発支援に広がっている。
- 社内説明では、モデル名を細かく並べるより「何ができるAIか」「どんな業務に使えるか」で分類すると伝わりやすい。
- Codex活用事例として、この資格学習PJ自体を社内向けAI活用ガイドに転用できる。
- 最新情報は変化が早いため、社内展開資料では「確認日」と「参照元」を残す運用が必要。
