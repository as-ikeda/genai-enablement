## 学習したこと

### AI社会の基本理念

AIを活用する社会で目指す基本理念として、次の3点を確認した。

1. **人間の尊厳が尊重される社会**
2. **多様な背景を持つ人々が、多様な幸せを追求できる社会**
3. **持続可能な社会**

これらの基本理念を実現するため、AI社会原則や、AIの開発・提供・利用に関わる事業者の指針が設けられている。

### 高度なAIシステムに関係する事業者に共通の指針

AIガバナンスを構築するための共通指針として、以下の10項目を確認した。

| 指針 | 一言での理解 |
| --- | --- |
| 人間中心 | AIは人の尊厳・権利・主体的な判断を尊重して活用する |
| 安全性 | 人や社会への危害を防ぎ、安全に利用できるようにする |
| 公平性 | 不当な差別や偏りを避ける |
| プライバシー保護 | 個人情報や私生活に関する情報を適切に扱う |
| セキュリティ確保 | 不正利用、漏えい、攻撃に備える |
| 透明性 | AIの利用目的、仕組み、限界などを説明できるようにする |
| アカウンタビリティ | 関係者が説明責任を果たし、適切に責任を負う |
| 教育・リテラシー | 利用者・事業者がAIの特性とリスクを理解する |
| 公正競争確保 | 競争を不当に妨げず、健全な市場環境を保つ |
| イノベーション | 社会課題の解決や新たな価値創出につなげる |

### 不明用語の一次整理

| 用語 | 試験向けの短い定義 |
| --- | --- |
| バイアス | データや設計に含まれる偏りにより、AIの判断が不公平・不正確になること |
| アカウンタビリティ | AIの開発・提供・利用に関わる者が、結果や対応について説明し責任を果たすこと |
| トレーサビリティ | データ、モデル、判断・操作の履歴を後から追跡・検証できること |
| ボランタリーコミットメント | 法令遵守に加え、事業者が自主的に公表・実践する安全・倫理面の約束や取組 |
| AIリテラシーレベルの確保 | 役割やリスクに応じて、AIを適切・安全に使うための知識と判断力を身につけること |
| リスキリング | 技術・業務の変化に対応するため、新しい知識や技能を学び直すこと |
| リスクに対するレジリエンス | リスクが発生しても、影響を抑え、対応・回復・改善を続けられる力 |

## 試験ポイント

- 3つの基本理念と、AI社会原則・事業者向け指針の関係を押さえる。
- 人間中心、安全性、公平性、プライバシー、セキュリティ、透明性、アカウンタビリティは、意味と具体例を対応付ける。
- バイアス、トレーサビリティ、ボランタリーコミットメント、リスキリング、レジリエンスを説明できるようにする。
- 原則はAI利用を止めるためのものではなく、リスクを管理しながら社会実装とイノベーションを進めるためのもの。

## 実務・社内展開メモ

- 社内で生成AIを使う際は、人間による最終確認、入力データの管理、利用目的の明確化、操作履歴の確保を基本の運用にする。
- AI活用ガイドは「禁止事項」だけでなく、利用者のリテラシー向上と、相談・改善につながる仕組みを含める。
