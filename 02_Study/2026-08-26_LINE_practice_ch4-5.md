## 確認できたこと

- GPT-o3ファミリーのうち、最も厳しい要件に対応する高精度モデルはo3-pro。
- GPT-o1シリーズは、推論の連鎖により数学・科学・プログラミングなどの複雑な問題解決能力を高めた。
- GitHub CopilotのSpacesは、開発者向けのコラボレーション環境・機能。
- OpenAIのOperatorでは、人間はプロンプトでタスクを指示し、AIが入力や資料作成などの操作を担う。
- CNNのプーリング層は、画像の特徴を維持しながらサイズを縮小し、計算量を減らす。
- GPT-4.1 miniは、GPT-4.1ファミリーでコストを大きく抑えたモデル。
- Gemini 1.5 Flashは、速度と低コストを重視したモデル。
- ディフュージョンモデルで、ノイズから画像を復元する過程は逆拡散過程。
- Copilot Studioは、企業が独自のCopilotをローコードで構築するためのツール。
- GPT-4oの音声応答は、最短232ミリ秒と人間の会話に近い応答速度を示す。
- GPT-4oの画像生成では、添付画像を参考にした画像生成が可能。
- Claude 3.5 Sonnetは、Opus 3と比較して高い推論性能と高速な応答を特徴とする。
- GPT-o4-mini-highは、reasoning_effort=highで推論の努力量を高める設定を持つ。
- RLHFで人間の評価を予測するために作られるモデルは報酬モデル。
- Transformerで入力データを処理し特徴を抽出する部分はエンコーダ。
- ChatGPTのCode Interpreterでアップロードしたファイルは、セッション内で一時的に利用される。
- Google DeepMindのVeo 3は、動画と音声を同時に生成できる。
- GPT-4oの画像生成は自己回帰モデルにより、画像内の文字列をトークンとして予測し、文字の生成精度を高めている。

## 第4章: 不明用語の復習

LINE確認問題で不明だった用語を、モデルの役割・サービスの用途・生成の仕組みで整理した。

| 用語 | 整理内容 |
| --- | --- |
| o1 / o3 / o3-pro | o1は推論モデルの系統、o3は後続世代、o3-proはより高精度・厳しい要件向け。 |
| Claude 3.5 Sonnet / Opus 3 | Opus 3はClaude 3世代の上位モデル。Claude 3.5 Sonnetは推論性能と速度を高め、コスト面でも有利な改良版。 |
| GitHub Copilot Spaces | リポジトリ・資料・Issueなどをまとめ、Copilotがその文脈を前提に回答するための共有スペース。 |
| Copilot Studio | 社内向けの独自Copilotをローコードで構築するMicrosoftのWebサービス。 |
| Operator | Web上でクリック・入力・スクロールなどの操作を担うAIエージェント。現在はChatGPTのエージェント機能へ統合。 |
| Veo 3 | Googleの動画生成モデル。Geminiなどから利用でき、映像と効果音・環境音・セリフをまとめて生成できる。 |
| プーリング層 | CNNで画像の重要な特徴を残して情報量を圧縮し、計算量を減らす。 |
| 拡散モデル / 逆拡散過程 | 学習では画像にノイズを加え、生成時はノイズを少しずつ取り除く。逆拡散過程はノイズから画像を生成する手順。 |
| 生成モデル / 報酬モデル | 生成モデルは文章・画像を作る。報酬モデルは人が好む回答を予測し、生成モデルの学習に使う。 |
| エンコーダ / デコーダ | エンコーダは入力を特徴表現へ変換、デコーダは特徴表現から出力を生成する。 |
| GPT-4o画像生成 | 自己回帰型で、画像内の文字や細かな指示、参照画像を活用した生成に強い。 |
| GPT-4.1 mini / Gemini 1.5 Flash | GPT-4.1 miniはOpenAIの小型・低コストモデル。Gemini 1.5 FlashはGoogleの高速・低コストモデル。 |
